# 💫 About Me:
Frontend Engineer with 4+ years of experience building scalable Admin dashboards and Learning Management System (LMS) platforms using React, Next.js, TypeScript, and GraphQL.<br><br>Experienced in designing reusable UI component systems, building complex operational dashboards, and optimizing frontend performance for high-traffic educational platforms used by thousands of learners and instructors.<br><br>Key contributions include building scheduling systems with calendar views, teacher and class management workflows, LMS learning flows including tests and progress tracking, and payment-integrated course purchasing systems.<br><br>Strong experience working with GraphQL (Apollo Client), Tailwind CSS, Material UI, and modern frontend architecture including Turborepo monorepos and shared design systems.
